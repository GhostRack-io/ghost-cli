- **VPN outgoing bypass:** `ghost vpn outgoing NAME bypass` (or `ghost vpn create --outgoing bypass`) lets the device's outgoing traffic use its own internet connection while incoming connections still arrive through the VPN, and `ghost vpn config`, `new-config` and `create --out` then write the matching config, for `wg-quick` on Linux. Earlier versions write the full tunnel's config for such a connection, which leaves the device without an internet connection.
- **Backup download link kept:** `ghost backup download` uses the backup's download link while it works, bought on the website or with ghost, without a new charge, and `ghost backup get` shows that link and until when it works. Once less than 12 hours are left, `--new-link` buys a new one, which works 24 hours.
- **Commands that need `--yes` show what they would do:** without `--yes`, a command such as `instance reinstall` or `instance delete` prints the target, the facts it touches and the command to repeat, and changes nothing. `--json` gives the code `confirmation_required` and the preview as the message; `--compact` keeps the one sentence.
- **Instance bandwidth limit:** `ghost instance bandwidth` lowers an instance's bandwidth limit below its offering's, or restores it.
- **Host upload speed:** `ghost provider host upload-speed` sets or clears a host's upload speed; renters are shown no more bandwidth than it on the host.
