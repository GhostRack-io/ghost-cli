- **Instance console:** `ghost instance console` reaches the console's own SSH server on the instance's host, through the console server. It keeps the host's key the first time and refuses a host that later shows another one, with both fingerprints. A host whose agent has no console server yet is named as such.
- **Saved SSH keys:** `ghost account ssh-keys remove` names the key it removes, signed with the account key. ghost 1.0.2 and earlier can no longer remove a key, and their `ghost instance console` is told to update.
