- **VPN connections:** `ghost vpn` creates and manages WireGuard VPN connections, with a config file or QR code from a key ghost generates.
- **Delayed deletion:** an older instance is turned off and deleted after a delay; ghost says when, `ghost instance keep` keeps it, and `ghost account pending list` shows the deletions waiting.
- **Backup kept first:** `ghost instance reinstall` and `ghost backup restore` of an older instance show what its locked backup costs at most and when the lock ends, before `--yes`. Earlier ghost versions are refused for these.
- **Dedicated IP for cloud instances:** `ghost instance gateway --tier dedicated-ip` gives a cloud instance an address of its own, or `--tier shared-ip` returns it to Shared IP, with the quote first.
- **Hardware filters:** `ghost catalog offerings` takes `--cpu-model`, `--min-x86-64-level`, `--memory`, `--disk` and `--redundant-disks`.
- **Pricing per capacity profile:** `ghost provider set-pricing --file` takes a file of parts (`terms`, `compute` per profile) for a host with several root pools.
