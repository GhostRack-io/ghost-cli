- **Approve instance actions started on the website:** `ghost account approve` approves a reinstall, an SSH access reset or a rescue boot asked for on the website. The approval screen shows each pasted SSH key by its fingerprint and other data by its SHA-256. Earlier versions refuse these requests and ask for an update.
- **Clone over the LAN mesh:** `ghost instance create --clone` makes a new VM as a copy of a VM on another host of the same LAN mesh, and `ghost instance mesh-hosts` and `ghost backup mesh-hosts` list the hosts that can take a copy now. `ghost catalog offerings --for-backup` accepts any of those hosts.
- **Trials rent any size:** a trial account's instances are no longer limited to 1 vCPU. Each holds its amount from the trial credit, and `ghost account` shows what balance a deposit must leave to lift the trial limits.
