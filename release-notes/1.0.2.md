- **Account keys:** a key line that ghost writes now starts with `ghostrack-account-seed-v1:`. Keys saved with `gigahost-account-seed-v1:` keep working, and the same key under either label is the same account.
- ghost 1.0.1 and earlier read only `gigahost-account-seed-v1:`. To use a key line written by a newer client there, update ghost, or change the start of the line to `gigahost-account-seed-v1:`.
